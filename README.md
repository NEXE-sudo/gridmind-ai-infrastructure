# GridMind

GridMind is a simulation-first data-centre operations console for evaluating
GPU workload scheduling decisions against accelerator capacity, memory, job
deadlines, node failures, and a facility power budget. It compares deterministic
policies and can optionally request scheduling proposals from an NVIDIA
Nemotron model through Nebius Token Factory.

The simulator and API are in [`Scaler_hackathon/`](./Scaler_hackathon/).
The legacy Scaler Energy Manager remains in the repository as historical
provenance; it is not GridMind's runtime.

## Quick start

Requirements: Python 3.11, [uv](https://docs.astral.sh/uv/), and Node.js 20+
with npm.

```bash
cd Scaler_hackathon
uv sync --locked --extra dev
uv run python -m pytest -q
cd agent-grid-view
npm ci
npm test -- --run
npm run lint
npx tsc -b --pretty false
npm run build
cd ..
uv run uvicorn server.gridmind_app:app --reload --port 7861
```

Open <http://127.0.0.1:7861/> for the built dashboard, or
<http://127.0.0.1:7861/docs> for the API. For dashboard hot reload, leave the
API running and start `npm run dev` in `Scaler_hackathon/agent-grid-view`; Vite
proxies API requests to port 7861.

## Reproducible experiment

From `Scaler_hackathon/`:

```bash
uv run python -m server.benchmarks \
  --config configs/demo.json --seeds 1,2,3 \
  --output-dir benchmarks/sample
```

This writes raw JSON run records, a CSV, and a readable Markdown report. The
checked-in [`sample report`](./Scaler_hackathon/benchmarks/sample/report.md)
was generated by the benchmark command; its Nemotron rows are offline fallback
runs, not live inference.

## Runtime model setup

Ordinary runs and tests do not call an external provider. To test a live
proposal, first obtain a Nebius Token Factory API key and verify an exact
NVIDIA model ID through the authenticated catalogue command documented in
[`MODEL_INTEGRATION.md`](./Scaler_hackathon/docs/MODEL_INTEGRATION.md). Set
`NEBIUS_API_KEY` and `GRIDMIND_MODEL` only in the server environment. Never use
a `VITE_*` variable for secrets. A model call is reported as live only after a
successful response; missing configuration and provider errors use the
deterministic fallback.

## Scope and submission readiness

GridMind controls no physical infrastructure. GPU capacity, power, energy,
and cost are synthetic estimates. See the
[architecture](./Scaler_hackathon/docs/GRIDMIND_ARCHITECTURE.md),
[benchmark methodology](./Scaler_hackathon/docs/BENCHMARK_METHODOLOGY.md),
[model integration](./Scaler_hackathon/docs/MODEL_INTEGRATION.md), and
[limitations and safety notes](./Scaler_hackathon/docs/LIMITATIONS_SAFETY.md).

The working code and reproducible local demo are provided; this checkout does
not contain verified live Token Factory inference, a public deployment, or a
recorded public demo video. No repository-level open-source license was present
at audit time. Those submission prerequisites are clearly tracked rather than
claimed complete. See the
[submission package and checklist](./Scaler_hackathon/docs/HACKATHON_SUBMISSION.md).
