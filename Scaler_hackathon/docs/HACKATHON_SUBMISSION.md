# NVIDIA × Nebius hackathon submission package

## Draft project description

GridMind is an AI-assisted data-centre operations simulator that schedules
synthetic GPU workloads against heterogeneous accelerator capacity, memory,
deadlines, failures, and a facility power budget. It compares FIFO, priority,
and resource-aware policies with a constrained NVIDIA Nemotron proposal path.
Every model proposal is validated by deterministic simulator rules before
execution; if inference is unavailable, malformed, or infeasible, the safe
resource-aware fallback runs instead. The dashboard exposes the queue, node
utilization, estimated energy, decisions, and paired multi-seed benchmark
results. Reproducible offline experiments demonstrate the evaluation path
without requiring an API key or GPU. The current implementation is simulation
only: it controls no physical infrastructure and uses synthetic power and
energy assumptions. Live Token Factory inference, public deployment, and the
public demo video remain to be verified/produced before submission.

## Technology statement

- **NVIDIA technology:** intended optional use of an NVIDIA open Nemotron
  model, selected by exact ID from the authorized Token Factory model
  catalogue. The model proposes a workload-to-node assignment and short
  rationale; it does not enforce resource safety.
- **Nebius integration:** server-side OpenAI-compatible Token Factory request
  to `https://api.tokenfactory.nebius.com/v1/`, configured by environment
  variables. The implementation contains a catalogue verifier and explicit
  catalogue/inference smoke commands.
- **What is proven here:** mocked provider parsing/fallback tests and
  reproducible offline simulator/benchmark execution.
- **What is not proven here:** catalogue ID availability, successful real
  inference, Nebius AI Cloud deployment, model price, or measured cloud cost.
  No key was available during this implementation.

## Material change from PR #1

PR #1 established the isolated GridMind simulator, baseline schedulers, a
guarded model-proposal path, FastAPI entry point, and initial tests while
preserving the legacy energy-grid code. This comprehensive change expands the
simulator with heterogeneous capacity, workload arrivals/lifecycle and
failures; adds shared metrics and reproducible paired multi-seed experiments;
completes API endpoints and scenario controls; replaces the stale legacy
dashboard route with a GridMind operations console; adds offline UI/API
coverage, CI, generated sample outputs, and end-to-end setup/submission
documentation. No claim of live inference, license, or deployment is implied.
