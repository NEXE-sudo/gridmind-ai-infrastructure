# GridMind focused demo walkthrough

Target video length: **2 minutes 30 seconds** (the official limit is under
three minutes). This walkthrough uses the checked-in, reproducible
`node_failure_recovery` run (seed 7) and the actual local dashboard. The report
and raw results are generated by simulator execution; do not hand-edit
measurements or present this offline run as live inference.

## Prepare from a clean checkout

```bash
cd Scaler_hackathon
uv sync --locked --extra dev
uv run python -m server.judge_demo --check
cd agent-grid-view
npm ci
npm run build
cd ..
uv run uvicorn server.gridmind_app:app --host 127.0.0.1 --port 7861
```

Open <http://127.0.0.1:7861/>. For the report, JSON records, and exact seeded
decision trace, run from `Scaler_hackathon/` in another terminal:

```bash
uv run python -m server.judge_demo
```

The checked-in artifacts are under
[`../benchmarks/judge-demo/`](../benchmarks/judge-demo/). The reproducibility
check re-executes all three policies and ignores only
`experiment.created_at` and each run's `created_at`; other fields must match.
The dashboard is local and remains useful without credentials or
internet access to an inference provider.

## Recording and publication checklist

- Capture the actual local app and report; do not fabricate screenshots,
  overlays, benchmark results, or provider activity.
- Avoid showing terminal history, environment dumps, `.env` files, keys,
  request headers, or other credentials.
- Keep synthetic energy/cost claims clearly labeled; do not call them measured
  infrastructure or provider savings.
- Use only recordings, logos, fonts, icons, and music for which usage rights
  are confirmed. The repository provenance audit identifies unclear inherited
  assets; do not include them in the recording until cleared or replaced.
- The video has not been recorded or published. Publish a publicly viewable
  YouTube video under three minutes only after owner review.
